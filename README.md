# Детекция определенных событий и объектов

# ------------------ ОБЪЕКТЫ ------------------
1. Пешеход
2. Транспорт (Машина, Мотоцикл, Автобус, Грузовик)

# ------------------ СОБЫТИЯ ------------------
1. Пешеход на зебре
2. Пешеход на проезжей части
3. Пешеход пересек границу проезжей части
4. Пешеход и транспорт одновременно в одной зоне (потенциальные опасные ситуации)

# ------------------ СТРУКТУРА ПРОЕКТА ------------------
**_detector_** (Содержит модель)
* models - Подпапка с моделями НН
* detection_methods.py - Функции для инференса и класс для приведения к единому формату всех детекцимй

**_roi_handler_** (Содержит все что связано с ROI)
* roi_creator.py - Функции для рисования и сохранения ROI
* roi_loader.py - Функции для загрузки ROI
* roi_event.py - Функции детекции пл событиям

**_utils_**
* clip_splitter.py - Функции для нарезки клипов
* drawing_handler.py - Функции отрисовок ROI и ББ
* paths.py - Пути к папкам и моделям проекта

## Первый запуск
1. Запустить python utils/paths.py — создаст структуру папок
2. Положить видео в data/video_raw
3. Запустить utils/clip_splitter.py и нарезать видео на клипы
4. Разметить ROI через roi_handler/roi_creater.py
5. Запустить main.py
